Раздел 1. Установка дистрибутива 
Скачан дистрибутив РЕД ОС с официального сайта и установлен в конфигурации "сервер минимальный" (без GUI)

1.1. Настройка сети
Выполнена в процессе установки ОС
1.2. Настройка имени хоста
Выполнена в процессе установки ОС
1.3. Проверка сетевой связности
ping -c 4 8.8.8.8 

Раздел 2. Управление программным обеспечением 

2.1. Обновление дистрибутива
dnf update -y
2.2. Установка пакетов из репозиториев
dnf install -y nginx libcap-ng-utils dnf-plugins-core
2.3. Установка локального RPM-пакета
Скачан dnf который установлен с помощью rpm

Раздел 3. Управление файловыми системами 

3.1. Создание файловой системы
Второй диск предварительно создан при установке ОС на виртуальную машину, 
в дальнейшем через командную строку отформатирован диск с присвоением MEPHI-WEB


Раздел 4. Управление сервисами
Запущен nginx, все действия записаны в journalctl

Раздел 5 Управление доступом
Создана директория /data/mephi-2026, созданы пользователи и группы, им присвоены права, согласно задания
SELinux в режиме Enforcing

Раздел 6. Аутентификация
Кураторы не имеют возможности войти локально
Установлена длина пароля не менее 12 символов и смена пароля каждые 90 дней

Раздел 7. Тестирование
curl работает, выводит текст с номером зачетной книжки
